## 一、已指出的设计问题（按先后）

### 1. 引擎地基错误（最核心）
- **问题**：我复用了幽灵工作台的"分解并行"引擎，前端"执行AI/质检AI/议院"身份是**按子任务 index 硬标的假名字**，不是真实流程 → 用户看到"质检AI 第一个回复"是假象。
- **老板原话**："为什么质检AI先回复？议员做总结？你到底有没有明白我的想法？" + "把幽灵扔掉，我们在做全新的东西"
- **正确方向**：**串行流水线**——执行AI用一个真实模型先做 → 完成 → 质检AI介入审 →（全自动）议院复核 → 收敛 → 交付。前端身份 = 真实串行阶段 + 真实模型，不硬标。

### 2. 半自动 vs 全自动 = 两种不同流水线（非仅并发数）
- **问题**：我把两者共用同一套并行引擎，只差并发数。
- **老板原话**："全自动和半自动是有区别的"
- **正确**：
  - 半自动 = **人机协作**：执行 → 质检 → **停下来给你看，你裁定**（通过/打回/让它改）
  - 全自动 = **AI 自治**：执行 → 质检 → 议院 → **AI 自己收敛修复** → 达标交付，你只在开始/验收出现

### 3. 任务流水线不该是孤立左栏，应融入侧边栏会话列表
- **问题**：我做了自建"任务流水线"左栏。
- **老板原话**："为什么不能显示在左侧边栏的会话区？在对话前标一个超级？或单独超级对话区，只显示超级对话标题"
- **方案 C（采纳）**：超级任务 = 一类特殊会话，归入侧边栏"超级任务"**独立分类组**（置顶）+ 条目"超级"气泡标记 + 专属 super 图标。

### 4. AI 浏览器不该焊死在右栏，应可收缩（像对话区右侧栏）
- **问题**：我做了固定 240px 右栏。
- **正确**：复用全局 DetailPanel（可收缩右侧栏），AI 浏览器作为其中一个 tab。
- **进一步纠正**：AI 浏览器**不需要手动开**，AI 操作时**自动浮层从右侧弹出**、可滑动；不需要不占位。顶栏按钮应换**右侧栏 SVG 开关图标**（非文字按钮）。

### 5. 点击超级任务会话应跳 /collab（非欢迎页）
- **问题**：selectSession 固定跳聊天欢迎页。
- **修复**：collabMode 会话 → 跳 /collab（已修）。

### 6. 条目前 SVG 应为"超级"专属标识
- **问题**：区分不足。
- **修复**：新增专属 `super` SVG（同心圆+星芒，紫色），用于导航入口/分类组/条目。全自动议院的头像应进一步用**对应品牌 LOGO**（见下）。

### 7. 全自动议院 = AI 群聊，头像用品牌 LOGO
- **老板原话**："全自动就像AI群聊一样，AI回复的头像就是对应品牌的AI LOGO"
- **正确**：每个 AI 发言 → 头像 = 它所属品牌/模型的 LOGO（DeepSeek/Kimi/GPT…），而非抽象"执/检/院"字母。
- **前提**：需要配套各品牌模型 key。

### 8. 顶栏 LOGO 不该是随便的"协"字
- **问题**：collab-logo 写死"协"。
- **修复**：改用 super 专属 SVG（紫），与侧边栏呼应（已修）。

### 9. 横栏下"多 AI 协作"标题冗余
- **问题**：多余标题 + 过时空态提示。
- **修复**：删除标题、改"左栏"→"左侧"（已修）。

### 10. 任务"无法上下滑动"
- **问题**：flex/grid 高度链没建好，外层 main-content overflow:hidden。
- **修复**：补 min-height:0 + overflow 约束（已修，提交 62961e4）。

## 四、关键决策记录（避免反复）

1. **模式本质**：半自动=人机协作(你裁定)；全自动=AI自治(收敛交付)。不同流水线。
2. **议院数量**：档位 标准3 / 深度6，锁上限，无"无限"。
3. **头像**：全自动议院 = 各品牌 LOGO（非抽象角色字母）。
4. **AI 浏览器**：自动浮层（需要时弹、不需要收起），顶栏用右侧栏 SVG 图标。
5. **任务在侧边栏**：超级任务独立分类组置顶 + 专属 super 图标。
6. **分层 vs 角色**：默认分层（机器→单AI→议院），展示时可角色化。
7. **串行优先**：前一个阶段完成才触发下一个，不并行分解。
