## Highlights

The top bar is shorter and now carries a real app menu. It was 56px tall only because
the logo lived in it; the logo is back in the sidebar where it belongs, so the bar
drops to 36px and the left side becomes File / View / Help.

Everything you reach from that menu was previously buried in the sidebar or had no
entry at all: show/hide the sidebar or the right panel, zoom the interface, switch to
full screen, check for updates, or open the log and data folders.

Search also stops wasting your time on instances that are down. A dead backend used to
cost the full timeout on every single query; now it is skipped for a minute after the
first failure.

## Features

- **App menu in the top bar** — File (new chat, new collaboration space, settings, quit),
  View (sidebar, right panel, zoom, dark mode, full screen) and Help (updates, about, log
  and data folders). The menu lives inside the sidebar's width, so the session title
  always starts at the workspace edge; collapse the sidebar and the menu hides entirely
  rather than crowding the title. (37084ca)

## Fixes

- **Windows: the session title sat on top of the logo** — a leftover offset from an
  earlier layout pulled the title to x=12px, exactly where the logo was. Removed. (e2faaf4)
- **Search no longer waits on a dead backend** — if a search instance fails or times out,
  it is skipped for 60 seconds, so the next query in a burst answers from cache instead of
  paying the same timeout again (measured 6.2s → 0.95s). (5584879)
- **Windows: caption buttons were invisible in dark mode** — the minimize/maximize/close
  glyphs kept their light-theme colour, which vanished against a dark bar. The window
  overlay now re-applies a light glyph colour whenever dark mode turns on. (37084ca)

## Engineering

- Comments written during this cycle are in English, per the repo convention. (95083cb)
- The macOS build is no longer blocked by a carrier-side rate limit: the mirror override
  now actually reaches electron-builder, and the release script reads the real artifact
  names instead of hard-coding them. (a26618f, e4ee31a)

## Known limits

- **The 36px bar and menu were verified in a real browser (both platforms, both
  languages) but not in a packaged desktop build.** The bar height is shared with the
  Windows caption overlay (TOP_BAR_HEIGHT), so a mismatch would shift the buttons; check
  that on first launch.
- Zoom levels are not persisted across restarts.
- Update-downloads are full packages for this version: the previous release renamed the
  macOS artifact (SUPERCRZY BOT-* → SUPERCRZY-*), which resegments the archive and makes
  binary diffing useless. The next small release should download incrementally again.
- The mainland search instance is still not the default: its port is unreachable across
  the border until ICP filing completes, so Chinese queries fall back to the overseas
  instance and take slightly longer.

## Install

- **macOS (Apple Silicon)** — download the `.dmg`, drag to Applications, right-click → Open on first launch
  (the build is unsigned).
- **Windows (x64)** — run the `.exe` setup; SmartScreen will ask once (the installer is unsigned).
- **Web / self-hosted** — Settings → About → *Check for updates* → *Update source* runs `git pull` + `pnpm install`
  + frontend build for you.

### 本次亮点

顶部横栏变矮了，左侧变成真正的菜单栏。之前横栏做 56px，只是因为 LOGO 放在里面；LOGO 回到侧边栏后，横栏降到 36px，左侧空间给了「文件 / 视图 / 帮助」。

菜单里的东西以前要么藏在侧边栏深处，要么根本没有入口：显示/隐藏侧边栏和右栏、界面缩放、全屏、检查更新、打开日志和数据目录。

搜索也不再为了挂掉的实例空等。以前后端不可用，每次查询都要耗满整个超时；现在失败一次后就跳过 60 秒。

### 新功能

- **顶部菜单栏** —— 文件（新建对话、新建协作空间、设置、退出）、视图（侧边栏、右栏、缩放、深色模式、全屏）、帮助（检查更新、关于、日志和数据目录）。菜单严格限制在侧边栏宽度内，所以会话标题始终对齐工作区左边缘；收起侧边栏时菜单全部隐藏，不挤占标题。

### 修复

- **Windows 上会话标题压在 LOGO 上** —— 早先布局遗留的偏移把标题拉到 x=12px，正好和 LOGO 重合。已移除。
- **搜索不再为挂掉的实例空等** —— 实例失败或超时后 60 秒内跳过，连续查询直接命中缓存，不再重复等同一个超时（实测 6.2 秒 → 0.95 秒）。
- **Windows 深色模式下窗口按钮看不见** —— 最小化/最大化/关闭三个图标沿用了浅色主题的颜色，在深色横栏上完全消失。现在切深色时会自动换成浅色图标。

### 工程

- 本轮新增的代码注释统一为英文，符合仓库约定。
- macOS 构建不再被运营商的限流卡住：镜像参数现在真正传到了 electron-builder，发版脚本也改为读取真实产物名，不再硬编码。

### 已知限制

- **36px 横栏和菜单只在浏览器里验证过（两个平台、两种语言），没有在打包后的桌面版验证。** 横栏高度和 Windows 窗口按钮层共用（TOP_BAR_HEIGHT），不一致会让按钮错位，首次启动请留意。
- 界面缩放比例不会跨重启保留。
- 本版更新需要下载完整包：上一版把 macOS 产物名从 `SUPERCRZY BOT-*` 改成了 `SUPERCRZY-*`，归档分块边界全变了，二进制差分失效。下一个小版本应该能恢复增量下载。
- 中国大陆的搜索实例仍不是默认：端口在备案完成前无法跨境访问，所以中文查询会回退到海外实例，稍慢一点。
