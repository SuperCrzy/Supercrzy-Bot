## Highlights

A finished reply now reads like a record of the work instead of a wall of output. Short narration paragraphs sit between collapsed tool rows, each row says what the batch did ("read 3 · edit 1 · 3s"), and the answer itself is three parts: a lead sentence, a few numbers, and an honest line about what is still unverified. Long tasks no longer fold everything into one bar that hides what was found.

Persistent goals are now available by default, with two ways in. Type `/goal` to open the goal editor above the input box, or simply describe a large project clearly — the assistant may propose a goal card above the input box on its own. A proposal arrives paused, marked "AI proposed": nothing runs until you press Start, and it never appears for everyday questions.

Sending without an account now says so. Previously the request went out, came back 401, and the app reported a connection interruption; now the composer asks you to sign in, and a session that expires mid-conversation stops with the same prompt instead of a misleading network error.

## Features

- **A reply you can read without expanding anything** — narration stays visible after the turn completes, each process segment collapses into its own summary row, and the final answer is a lead-in plus numbered facts plus a boundary line.
- **Goals you can open and goals the assistant proposes** — `/goal` in the slash menu; the assistant proposes only for large, explicit projects, at most once per session, and never starts one itself.
- **Goal continuation after verified writes** — a turn that wrote a file may continue when the same turn read it back and cited that read; network, shell and device operations still stop after one turn.

## Fixes

- **No skill disappears from the installed list** — the index no longer drops entries when it exceeds its length budget, and a duplicate name now opens one skill instead of nothing.

## Known limits

- The reply template and the goal proposal are covered by unit tests; this build is their first run against a real model. If the assistant proposes goals for small tasks, that is the thing to report.
- Goal execution still requires a signed-in account. You can create or receive a goal while signed out, but Start will ask you to sign in first.
- Builds remain unsigned: macOS needs right-click → Open on first launch, Windows shows one SmartScreen prompt.

## Install

- **macOS (Apple Silicon)** — download the `.dmg`, drag to Applications, right-click → Open on first launch
  (the build is unsigned).
- **Windows (x64)** — run the `.exe` setup; SmartScreen will ask once (the installer is unsigned).
- **Web / self-hosted** — Settings → About → *Check for updates* → *Update source* runs `git pull` + `pnpm install`
  + frontend build for you.
