## Highlights

**Speech playback no longer stops mid-sentence.** Four separate root causes, all fixed: the sentence
splitter ignored English periods (on a real 2,724-character English corpus, **65% of split points
landed inside a sentence**); the client fired `push`/`end` and forgot about them, so an `end` arriving
before the last chunk was discarded outright (observed audio was only the first 62,784 bytes); the server
retried without checking whether it had already written audio for that turn, so a re-sent stream spoke the
same sentence twice (8,192 → 16,384 bytes); and a client pause longer than 30s was mistaken for an upstream
disconnect. Chunk batching now throttles on **unplayed audio seconds** instead of character count — the old
fixed-size rule starved the player for **46.6 s** under slow generation, the new rule keeps gaps at 0.6 s and
always splits on a sentence boundary. When synthesis genuinely fails, the server records it and the UI shows
**"Playback interrupted"** with a resume action that continues from the next sentence boundary.

**Background tasks get a dock.** Long-running commands no longer leave you waiting in the dark. A bar above
the composer shows `N background tasks running`, expands upward in place (pushing messages up rather than
covering them), and the delete action only appears on row hover with a confirmation. When a task finishes,
the server pushes `running → terminal` over SSE and the conclusion (exit code plus the last 2,000 characters
of output) is injected as a continuation, so the agent keeps working without you prompting it. State lives on
the server, so a page refresh does not lose it. The detail panel streams a single task's incremental output
via a cursor and can cancel it.

**Process folding adapts to task size.** Folded processes used to collapse unconditionally into one line at the
very top of a message — a 3-step task lost its evidence, and the reading order (narration → process → answer)
was broken. Now short tasks (≤3 tools and ≤8 process nodes) render flat, and long ones still fold into a single
row but stay **where the process first appears**, preserving chronological order. The thresholds live in
`utils/process-fold.ts` as pure functions with four assertions.

**Tool recall switched to BM25.** The old recall was a single `name.includes(query)` check — substring only, no
ranking, no top-k, and a Chinese query could never match an English tool name (`query="图像"` did not find
`generate_image`); on a miss it dumped all 34 on-demand tools to the model. It is now a hand-written BM25
(no new dependencies, k1=1.2 / b=0.75) with field weights name×3 / alias×2 / description×1, Chinese bigram
tokenization, and a relative cut-off at 30% of the top score. A miss returns sloppy-suggestion hints and five
common examples instead of the whole catalogue.

**Capability manifest is derived, not hand-listed.** The `tool_search` allow-list was 39 hand-copied names and
had already drifted — `file_delete`, `memory_consolidate`, `make_article` and `browser` were missing, so any of
them promoted from on-demand to always-on would have been silently dropped. It is now derived from the registry.
Activation after a `tool_search` call used to be a **regex over the returned prose** (`已加载，可直接调用` plus
the tool name scraped from each line) — editing that wording by one character made on-demand tools permanently
unreachable, with no error. Activation now replays the same search using the call's actual arguments, so prose
and activation are fully decoupled. The per-session manifest carries provenance (builtin / skill / mcp) and a
stable hash, which answers "who brought this tool in" and "what disappeared when I disabled that skill".

**Idle capability suggestions.** 16 of the 43 registered tools have never been called and the system had no idea.
Usage is now tracked per day: anything idle for ≥14 days is listed on the Usage page with its idle days and last
use. Tools installed today are never suggested (new is not idle), and "don't remind me in this version" is keyed
to a capability version, so a changed description brings the suggestion back.

**Three more tool views.** `tool_search` shows the query plus the activated names; `browser` and `computer_use`
share an action badge / target / outcome layout instead of dumping raw argument JSON. No tool in the top 10 by
call volume falls through to the generic renderer any more.

## Engineering

- **CSS gate**: removed 16 zero-reference tokens and mapped 44 legacy alias usages onto real tokens
  (`--danger*` → `--error`, `--code-bg` → `--bg-code`, …). `check-css-vars` now fails on declarations nobody
  uses, and stylelint runs in `pnpm verify`.
- **Permission contract**: `validate:permission` pins the tier list to be identical between the display layer
  and the decision layer, `TIER_META` to cover every tier, and the desktop deploy copy to match the source
  byte-for-byte.
- **Capability contract**: `validate:tools` gained four assertions — the allow-list must be derived, activation
  must be data-driven, recall must be deterministic, and any tool named in on-demand guidance must exist.
- `app.ts` accepts an optional `HOST` environment variable; unset keeps the Node default binding.
- **Contributing policy**: English is now the default language for code comments, commit bodies, PRs, issues,
  release notes and published documentation. See `CONTRIBUTING.md`.

## Install

- **macOS (Apple Silicon)** — download the `.dmg`, drag to Applications, right-click → Open on first launch
  (the build is unsigned).
- **Windows (x64)** — run the `.exe` setup; SmartScreen will ask once (the installer is unsigned).
- **Web / self-hosted** — Settings → About → *Check for updates* → *Update source* runs `git pull` + `pnpm install`
  + frontend build for you.

**朗读不再中途断掉。** 四处根因全部修掉：切句正则不认英文句号（真库 2724 字英文语料实测 **65% 的切点落在句子中间**）；
