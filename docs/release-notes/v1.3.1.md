## Highlights

Windows sign-in was effectively broken in 1.3.0: the app handed the browser a
login link that the Windows shell cut short at the first `&`, so the sign-in
page rejected it with "loopback redirects must send a PKCE challenge". The
browser is now opened without going through the Windows command shell, and the
full link — including the PKCE challenge — arrives intact.

The same release tidies two window behaviours people hit right away. Maximising
the right detail panel (AI browser, preview) no longer covers the app's title
bar, and the maximised state now has three obvious ways out: a restore button
in the panel's tab strip, the Escape key, or simply switching tabs. On Windows,
the Chinese/English switch on the sign-in screen no longer hides behind the
system minimise/maximise/close buttons.

## Features

_No new user-facing features in this release._

## Fixes

- **open the system browser without cmd on Windows** — the sign-in link was split at the first `&` by the Windows command shell, so the challenge never reached the sign-in page; `rundll32` opens it intact. (4736f40)
- **keep the maximised detail panel below the title bar** — maximising no longer swallows the title strip or traps you inside the panel; restore button, Esc and tab switching all get you back. (64ab474)
- **move the login language switch clear of Windows controls** — the Chinese/English switch on the sign-in screen sits left of the window control buttons on Windows. (3fd6636)
- **publish the update feed instead of a path with a newline in it** — release tooling fix; in-app update checks resolve cleanly. (1685097)

## Engineering

_This release ships three regression checks under `scripts/diag/` that measure
the fixed geometry in a real browser, each with a control run that reproduces
the original bug when the fix is disabled._

## Known limits

- The two Windows fixes (sign-in, language switch) were verified against server
  logs and browser-measured geometry, **not yet on a physical Windows machine**.
- The panel-maximise fix was verified in a real browser against the app shell,
  not inside the packaged Electron build.

## Install

- **macOS (Apple Silicon)** — download the `.dmg`, drag to Applications, right-click → Open on first launch
  (the build is unsigned).
- **Windows (x64)** — run the `.exe` setup; SmartScreen will ask once (the installer is unsigned).
- **Web / self-hosted** — Settings → About → *Check for updates* → *Update source* runs `git pull` + `pnpm install`
  + frontend build for you.
