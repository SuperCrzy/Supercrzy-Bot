## Highlights

Reading the web works properly again. Pages that arrive compressed were being
decoded as raw text, sites that hold their stylesheets in hidden template
elements returned a page of CSS instead of the article, and on some networks the
connection was closed before the page came back at all. All three are fixed, and
fetching was verified against live sites rather than mocks.

Replies are harder to lose. An answer that finishes after you have already sent
the next message is now saved against its own message instead of the newest one,
deleted messages no longer come back, and a partial answer survives an error
mid-stream instead of being wiped. The stop button interrupts reliably and says
so afterwards.

Search and news are usable from a machine behind a mainland China connection.
The search relay no longer pays a 30-second timeout on every query, and a cached
headline list is labelled as cached rather than presented as today's news.

## Fixes

### Reading the web

- **Compressed pages are decoded correctly.** A page whose body arrives gzipped
  was being read as if it were text, which turned every Chinese site into a wall
  of replacement characters.
- **Stylesheets no longer replace the article.** Some sites keep a stylesheet
  template inside a hidden textarea; that template was being returned as the page
  body, pushing the real text past the length limit.
- **Sites that close the connection during the handshake now load.** The
  transport now negotiates HTTP/1.1 explicitly.
- **Chinese pages in legacy encodings are readable.** GBK is detected from the
  response header, the document declaration or a byte-order mark.
- **Fetched text is cleaner.** Scripts and styles are dropped, paragraph breaks
  are kept, and entities are decoded.

### What gets saved

- **A finished answer is saved against its own message.** Sending the next
  message while a long answer is still animating no longer overwrites it.
- **Deleted messages stay deleted.** A save queued before the delete can no
  longer write the message back.
- **A partial answer survives an error.** Text already received is kept, and the
  real error is shown instead of a generic "connection interrupted".
- **"Retrying" means retrying.** The notice clears once the answer finishes, and
  the stream is not closed while a retry is still coming.

### Typing and stopping

- **Stopping works and is honest about it.** The interruption lands on the reply
  you stopped, and a failed stop request tells you the background task may still
  be running.
- **Chinese input no longer sends half-typed messages.** Some input methods
  report a key code that made Enter look like a send.
- **Drafts follow their own conversation.** Half-written text and attachments no
  longer travel to whichever conversation you switch to.
- **Queued messages stay with their conversation.** Switching away while a task
  runs no longer sends them somewhere else.

### Search and news

- **Search answers in about a second instead of timing out.** A relay keeps the
  overseas endpoint reachable from a mainland connection.
- **A dead source is not reported as "no news".** The feed is cached on disk and
  stale rows are labelled.

### Security

- **Fetched URLs cannot reach your machine.** Loopback, private ranges, cloud
  metadata addresses and redirects into them are refused, and every resolved
  address is checked before the connection is made.
- **File preview stays inside the workspace.** Links pointing outside it, or at
  credential files, are rejected.

## New in this build

### Undo what the assistant changed

- **See exactly what changed in each file.** After a turn that edited files, open
  the checkpoint and get a line-by-line diff per file instead of a list of names.
- **Roll back one file, or all of them.** Keep the rest of the turn and undo the
  one edit that was wrong. A file the turn created is removed on rollback.

### Personality files

- **SOUL.md / USER.md / IDENTITY.md** in your data directory, loaded into every
  conversation. Write down your conventions and preferences once instead of
  restating them each time you open a new chat.

### Diagnostics

- **Export diagnostics** from the Logs page: version, environment, capability
  counts and the log tail in one file, with secrets masked. Attach it to a report
  instead of describing the problem in prose.

### Artifact centre

- **One place for every file the assistant has produced**, across conversations,
  with search and a jump back to the session that made it.

### Background commands

- **Background tasks now run inside the same kernel sandbox as foreground ones.**
  Previously the same command was isolated when run directly and not when sent to
  the background.

## Engineering

- The agent now refuses to treat a normally-closed stream as a successful task.
- Artifact cards report themselves through one shared path, so a tool that writes
  a file cannot silently omit it from the panel.
- Two oversized components were split to stay under the file-size gate.

## Known limits

- Verified on macOS arm64 against live sites. Windows and iPhone have not been
  re-tested this cycle.
- Fetching was checked from a mainland China connection behind a fake-IP proxy;
  other proxy styles may behave differently.
- Account-level isolation of local conversations is designed but not implemented.
  Switching accounts on a shared machine can still show earlier conversations.
- A full instalment-level run (open the packaged app, run a task) has not been
  done for this build.

## 本次更新

**网页抓取恢复正常。** 压缩传输的页面此前被当成纯文本解码，把样式表模板藏在隐藏 textarea 里的站点此前返回的是一整页 CSS，某些网络下连接还会在握手阶段被断开。三处都已修复，并用真实站点验证，不只是模拟。

**回答更难丢失。** 长回答在你已经发出下一条消息后才结束时，现在会存回它自己的消息而不是最新那条；已删除的消息不会再回来；流式中途出错时，已收到的部分会保留，而不是被清空。停止按钮可靠生效，并在之后如实说明状态。

**搜索和新闻在墙内网络可用。** 搜索中继不再让每次查询白等 30 秒超时；缓存下来的头条会标明是缓存，而不是冒充今天的新闻。

## 修复

### 读取网页

- **压缩页面正确解码**：此前 gzip 传输的正文被当文本读，中文站点会变成一整片乱码。
- **不再拿样式表当正文**：部分站点把样式表模板放在隐藏 textarea 里，那段模板被当页面正文返回，把真实内容挤到长度上限之外。
- **握手阶段被断开的站点现在能打开**：传输层显式协商 HTTP/1.1。
- **旧编码中文页面可正常阅读**：按响应头、文档声明或字节标记识别 GBK。
- **提取出的文本更干净**：剔除脚本与样式，保留段落分隔，实体正确解码。

### 保存行为

- **结束的回答存回自己的消息**：长回答还在播放动画时发出下一条，不会覆盖它。
- **删除的消息保持删除**：删除前排队的保存请求不会把它写回来。
- **出错时保留已收到的内容**：显示真实错误，而不是笼统的「连接中断」。
- **「正在重试」就是正在重试**：回答结束后提示会清除，重试期间不提前关闭流。

### 输入与停止

- **停止可靠且如实**：中断落在你停的那条回复上；请求失败时会提示后台任务可能仍在执行。
- **中文输入不再误发送**：部分输入法的键码让回车被当成发送。
- **草稿跟着自己的会话**：写了一半的文字和附件不再跟着切换。
- **排队消息留在原会话**：任务运行时切走，不会发到别处。

### 搜索与新闻

- **搜索约一秒返回，不再超时**：中继让海外端点从墙内可达。
- **源站不可用不再等同「没有新闻」**：订阅源缓存到磁盘，过期的条目会标注。

### 安全

- **抓取地址无法触达本机**：回环、私网、云元数据地址以及跳转进这些地址都会被拒绝，连接建立前会校验每个解析结果。
- **文件预览不越出工作区**：指向工作区外或凭据文件的链接会被拒绝。

## 本版新增

### 撤销 AI 的改动

- **逐文件看改动**：一轮任务改过文件后，打开检查点能看到每个文件的行级 diff，而不是只有文件名。
- **单文件回滚或整轮回滚**：保留其余改动，只撤销出错的那一个。本轮新建的文件回滚时会被删除。

### 人格文件

- **SOUL.md / USER.md / IDENTITY.md** 放在数据目录，每次对话都会加载。把自己的习惯和约定写一次，不用每开一个新对话就重复交代。

### 诊断包

- **日志页可导出诊断包**：版本、环境、能力计数与日志尾部打包成一个文件，密钥已脱敏。报障时直接附上，不用靠文字描述。

### 制品中心

- **一个地方看所有产物**：跨会话列出 AI 生成过的文件，可搜索，可跳回生成它的会话。

### 后台命令

- **后台任务现在与前台走同一套内核沙箱**。此前同一条命令前台隔离、后台不隔离。

## 已知限制

- 本轮在 macOS arm64 上对真实站点验证；Windows 与 iPhone 本轮未重新测试。
- 抓取是在墙内 fake-IP 代理环境下验证的；其他代理形态可能不同。
- 本地会话的账号级隔离已设计但未实现，共享电脑切换账号仍可能看到先前会话。
- 本构建尚未完成「装包后打开 App 跑一个任务」整机验证。
