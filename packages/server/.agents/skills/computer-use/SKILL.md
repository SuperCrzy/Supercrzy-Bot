# computer-use

操控用户电脑的桌面控制能力：截屏查看屏幕、移动鼠标点击、输入文字、发送按键、滚动页面、打开应用。

## 权限要求

- 必须在「完全访问」(full) 权限下才能使用——会话权限不是 full 时调用会返回提示，引导用户切换权限后重试。
- 调用前通常需要用户授权确认（危险工具）。

## 核心用法

调用 `computer_use` 工具，参数 `action` + `args`：

| action | 作用 | 参数 |
|---|---|---|
| `screenshot` | 截取当前屏幕 | 无 |
| `click` | 点击指定坐标 | `{ x, y }` |
| `right_click` | 右键点击 | `{ x, y }` |
| `double_click` | 双击 | `{ x, y }` |
| `type` | 输入文本 | `{ text }` |
| `key` | 发送按键组合 | `{ combo }`（如 `command+space`） |
| `scroll` | 滚动 | `{ clicks }`（正=向下） |
| `move` | 移动鼠标 | `{ x, y }` |
| `open` | 打开应用 | `{ name }`（如 `Safari`、`微信`） |

## 推荐流程（操作类任务）

1. 先 `screenshot` 查看当前屏幕，确认界面布局
2. 根据截图坐标执行 `click` / `type` / `key` 等操作
3. 操作后再 `screenshot` 验证结果是否生效
4. 需要打开应用时用 `open`（先尝试应用名，失败再试英文名/路径）

## 安全边界

- 仅操作用户明确授权的动作，敏感操作（删除、付费、发送）前必须说明并等待确认
- 只操作与任务相关的窗口，不随意点击无关内容
- 输入密码等敏感信息前先询问用户

## 典型场景

- 「打开浏览器帮我搜索一个东西」
- 「打开微信/邮箱/某个软件」
- 「帮我截图看看现在屏幕上有啥」
- 「把窗口里那段文字复制出来」
- 「滚动页面到最下面」
